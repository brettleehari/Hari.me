### 2022-Present -- Production AI in Enterprise

- **Agent Interpretability Tool**
  - *What it does:* Surfaces what's actually happening under the hood in a coding agent — the decisions, the context, the failure modes.
  - *Why it mattered:* Agents are black boxes by default. If you can't explain what an agent did and why, you can't debug it, you can't trust it, and you can't improve it. This tool makes the invisible visible.
  - *What it taught me:* Interpretability isn't a research luxury — it's a product requirement. Enterprise buyers won't adopt what they can't audit.
  - *Evidence:* <!-- TODO: link to repo -->

- **General-Purpose Context Management System**
  - *What it does:* Infrastructure for managing context across AI system interactions — what goes in, what stays, what gets evicted, and why.
  - *Why it mattered:* Context is the scarcest resource in any LLM-based system. Most teams treat it as an afterthought. This treats it as first-class infrastructure.
  - *What it taught me:* Context management is where product intuition and systems engineering intersect. Get it wrong and the model looks broken. Get it right and nobody notices — which is the point.
